# 읽고 모르면 물어보셈

 - 나 편하려고 클래스 다 찢어 둔거임 통합할때는 한 파일에 합칠예정 개개인 파일에 오류가 있는건 서로 연동되는걸 다 찢어서 그럼

 - 모든 변수는 그냥 임의로 파파고 돌려서 그럴싸한거 사용한거임 더 편하거나 나은거 있다고 생각하면 말해줘

 - BudgetManager.py : 카테고리 지출 내역이지만  카테고리를 지정한 상태가 아니라서 후에 정보들어올때 따로 클래스 사용해서 입력해야할거임
 
 - FixedExpense.py : 순수 고정지출 이라는 데이터를 나타내는 클래스

 - FixedExpenseManager.py : 고정 지출 데이터를 추가, 삭제, 조회등 관리하는 클래스, 앞선 FixedExpense는 그냥 깡통이라고 생각해도 되고 고정지출 관련 문제 있으면 여기 일거임

 - WarningBudget.py : 예산 75퍼센트때 1차 90퍼센트때 2차 경고 예정 맘에 안들어서 수정예정
