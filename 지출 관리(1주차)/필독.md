 - BudgetManager.py : 카테고리 지출 내역이지만  카테고리를 지정한 상태가 아니라서 후에 정보들어올때 따로 클래스 사용해서 입력해야할거임
 ->> 클래스 내 함수 사용방법 :
 set_category_budget()      카테고리, 금액       카테고리 예산 저장

 get_available_budget()     없음                사용 가능 예산 반환

 get_total_used()           전체 지출 목록       전체 소비 합계 반환

 get_category_used()        지출 목록, 카테고리  카테고리별 소비 합계 반환

 get_remaining_budget()     전체 지출 목록       전체 남은 예산 반환

 get_category_remaining()   지출 목록, 카테고리  카테고리별 남은 예산 반환

 get_total_usage_rate()     전체 지출 목록       전체 예산 사용률 반환

 get_category_usage_rate()  지출 목록, 카테고리  카테고리별 사용률 반환

 get_total_warning()        전체 지출 목록       전체 예산 경고 반환

 get_category_warning()     지출 목록, 카테고리  카테고리별 경고 반환

 show_category_budget()     전체 지출 목록       카테고리별 현황 출력

 show_total_budget()        전체 지출 목록       전체 예산 현황 출력

 - FixedExpenseManager.py : 고정 지출 데이터를 추가, 삭제, 조회등 관리하는 클래스, 앞선 FixedExpense는 그냥 깡통이라고 생각해도 되고 고정지출 관련 문제 있으면 여기 일거임
  ->> 클래스 내 함수 사용방법 :
__init__()           없음                 빈 리스트 생성

add_expense()        이름, 카테고리, 금액  리스트에 객체 추가

remove_expense()     이름                 삭제 성공 여부 True/False

update_expense()     이름, 새로운 금액     수정 성공 여부 True/False

show_expenses()      없음                 전체 고정 지출 출력

get_total_expense()  없음                 고정 지출 총합 반환
